# Notes-Manager
- Менеджер заметок - приложение для создания, редактирования, удаления и хранения текстовых заметок.
- Простое приложение созданное в учебных целях.

## Технологии
- **C#** (.NET 8)
- CLI

## Функции
- Создание заметок
- Редактирование
- Удаление
- Сохранение в файл
- Загрузка из файла
  
## Структура проекта
- Notes-Manager/
- ├── .github
- ├── NotesManager
 -    ├── Program.cs          # Точка входа
 -    ├── Note.cs             # Модель заметки
 -    ├── NoteManager.cs      # Логика работы с заметками
 -    └── README.md           # Описание проекта
 -    └── NotesManager.sln

## Запуск
- cd [путь до папки]
- dotnet run
