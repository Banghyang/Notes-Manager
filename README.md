# Notes-Manager
- Менеджер заметок - приложение для создания, редактирования, удаления и хранения текстовых заметок.
- Простое приложение созданное в учебных целях.

## Технологии
- **C#** (.NET 8)
- CLI

## Функции
- Создание заметок
- Редактирование
- Удаление
- Сохранение в файл
- Загрузка из файла
