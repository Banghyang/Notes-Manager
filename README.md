# Notes-Manager
- Менеджер заметок - приложение для создания, редактирования, удаления и хранения текстовых заметок.
- Простое приложение созданное в учебных целях.

## Технологии
- **C#** (.NET 8)
- CLI

## Функции
- Создание заметок
- Редактирование
- Удаление
- Сохранение в файл
- Загрузка из файла
  
## Структура проекта
Notes-Manager/
- ├── .github
- ├── NotesManager
- ____├── Program.cs          # Основной код
- ____├── Note.cs             # Модель заметки
- ____├── NoteManager.csproj
- ____└── README.md           # Описание проекта
- └── NotesManager.sln

## Запуск
- cd [путь до папки]
- dotnet run
